# SPIRAL CACTUS — Website V2

An independent, bilingual (EN/FR) Spiral Cactus site built from the project presentations, Media Kit, communication strategy and existing visual assets. No backend, npm packages, frameworks or subscriptions are required. Compatible with free GitHub Pages public repositories.

## Launch

1. Unzip this file on your computer.
2. Open your existing GitHub repository `spiralcactus-brussels/spiral-cactus`.
3. Upload **ALL** `.html`, `.css`, `.js` files and the entire **`assets/` folder** to the root (not the ZIP itself).
4. If Github asks about existing files, replace them and commit changes. Browser upload of files inside folders can be unreliable; drag the whole extracted contents, with the `assets` folder, onto the GitHub uploader and confirm directory structure. You can also use GitHub Desktop to synchronize the folder.
5. In Settings > Pages, keep Deploy from a branch, `main`, `/(root)`.
6. Visit https://spiralcactus-brussels.github.io/spiral-cactus/

## Structure

- `index.html` — brand-first homepage.
- `discover.html` — story, brand symbolism, values and planned 500-person concept.
- `experiences.html` — current work vs. plans (clearly labelled).
- `events.html` — Acid Edition and first Brussels Rave Night edition.
- `gallery.html` — actual existing posters/artist visuals.
- `contact.html` — collaboration pathways and confirmed generic email.
- `styles.css` — design system.
- `script.js` — language switch, mobile menu, scroll reveal and date-sensitive event CTA.
- `translations.js` — all FR/EN website strings. Modify your copy here.
- `assets/` — compressed originals from the SpiralCactus project.

## What to update later

- Replace `assets/logo-white.png` with the final approved logo from your Drive. Keep the filename to update all pages instantly.
- Update colours in `styles.css`: `--lime`, `--orange`, `--purple`, `--teal` after visual brand guidelines are confirmed.
- Add original photos/videos after confirming permission to publish them.
- Check the external ticket link in `events.html` before sharing publicly.
- Event dated 16 October 2026 becomes a gallery link automatically after 17 October 07:00 Brussels time; update with new events as announced.
- Replace or expand social URLs when accounts are confirmed.
- An actual email subscription form needs a separate provider (e.g. Buttondown, MailerLite, Brevo). A static GitHub Pages site by itself cannot collect/store email or process payments.
- Github Pages offers hosting for free, but the custom domain is paid through its registrar and must be controlled by you.

## Content handling

Statements about the planned venue (~500 people), workshops, corporate services and festival are written as future/development activities. They are NOT described as currently operational. No financial projections, private funding targets, third-party contacts or internal staff data are published.
