MEDIA MANAGER

Toutes les photos et vidéos de SpiralCactus, organisées par événement. Importez les fichiers originaux ou un ZIP : le système conserve chaque photographie HD et crée un aperçu rapide pour la galerie. Les vidéos originales sont envoyées par morceaux. Le site reste hébergé sur GitHub Pages.

1 · Connexion sécurisée

Le mot de passe reste dans cette page ; il n'est pas envoyé à GitHub. L'adresse du serveur est conservée uniquement dans ce navigateur.

2 · Choisir l'événement

L'album sélectionné reçoit uniquement ses propres photos et vidéos. Les événements sont récupérés de votre site.

3 · Importer vos médias

Glissez les photos, vidéos ou un ZIP ici

Ou utilisez le bouton ci-dessous. Sélection multiple possible.

    Photos : deux fichiers enregistrés automatiquement (original HD inchangé + aperçu WebP optimisé, 1920 px). Attention : l'original HD peut contenir des métadonnées EXIF, notamment GPS ; vérifiez les fichiers avant publication. Vidéos : qualité originale conservée, MP4 H.264/AAC recommandé pour la lecture. Les gros fichiers sont envoyés par morceaux de 8 Mo.
